# 06-02-PLAN: ManageQuestions & ManageRoles UI

## Overview
Build the interactive Question CRUD table (with Add/Edit modal and Bulk Import panel) and the Roles management page, all within the AdminLayout sidebar shell.

## Task Breakdown

### Task 1: ManageQuestions Page
- **File**: `client/src/pages/admin/AdminQuestions.jsx`
- Features:
  - Searchable/filterable table (by role, type, difficulty, isActive).
  - "Add Question" button → opens an `AddEditQuestionModal` with form fields: text, role, type, difficulty, expectedAnswer, keyPoints (comma-separated), options[0-3] (shown only if type=aptitude), correctOption.
  - Edit (pencil icon) → same modal pre-filled.
  - Delete (trash icon) → confirmation dialog → soft-deletes (`isActive: false`).
  - "Bulk Import" tab → JSON textarea → preview count → "Import" button → calls `POST /api/admin/questions/bulk`.

### Task 2: ManageRoles Page
- **File**: `client/src/pages/admin/AdminRoles.jsx`
- Features:
  - Table of roles: Name, Display Name, Description, Status (Active/Inactive badge), Actions.
  - "Add Role" form (inline or modal): name (auto-uppercased), displayName, description.
  - Toggle switch on each row for `isActive`.
  - Delete button (removes role from DB).

### Task 3: Wire up Admin Routes in App.jsx
- Mount:
  - `/admin` → `AdminDashboard`
  - `/admin/questions` → `AdminQuestions`
  - `/admin/roles` → `AdminRoles`
  - `/admin/users` → `AdminUsers`
- All wrapped in `AdminRoute` (checks `user.role === 'admin'`).

## Verification
- Admin can create a question, see it appear in the table, edit its difficulty, and soft-delete it.
- Admin can add a new role, toggle it inactive, and see the status change.
