# 06-01-PLAN: Admin Middleware, Stats APIs & User Progress Viewer

## Overview
Add admin-only middleware, implement aggregation APIs for platform stats, role/question CRUD endpoints, and build the admin dashboard + user progress list UI.

## Task Breakdown

### Task 1: Admin Middleware
- **File**: `server/src/middleware/adminOnly.js`
- Check `req.user.role === 'admin'`; return 403 with message `'Admin access required'` if not.

### Task 2: Admin Routes & Controller
- **Files**: `server/src/routes/admin.js`, `server/src/controllers/adminController.js`
- Endpoints:
  - `GET /api/admin/stats` — Aggregates: total users, total questions by type/difficulty, average overall score across all PracticeAttempt records.
  - `GET /api/admin/users` — Returns all users (name, email, role, createdAt) with per-user stats: total attempts, average score (joined from PracticeAttempt).
  - `GET /api/admin/questions` — Paginated question list with full fields.
  - `POST /api/admin/questions` — Create single question.
  - `POST /api/admin/questions/bulk` — Bulk insert array of questions.
  - `PUT /api/admin/questions/:id` — Update question fields.
  - `DELETE /api/admin/questions/:id` — Soft-delete (set `isActive: false`).
  - `GET /api/admin/roles` — List all roles.
  - `POST /api/admin/roles` — Create new role.
  - `PUT /api/admin/roles/:id` — Update role (displayName, description, isActive toggle).
  - `DELETE /api/admin/roles/:id` — Delete role.
- Register in `server/src/index.js` at `/api/admin`.

### Task 3: Admin Dashboard UI
- **Files**: 
  - `client/src/pages/admin/AdminDashboard.jsx` — Stats cards (Total Users, Total Questions, Platform Avg Score) with mini charts/sparklines.
  - `client/src/pages/admin/AdminUsers.jsx` — Table of all students with columns: Name, Email, Attempts, Avg Score, Joined.
  - `client/src/components/AdminLayout.jsx` — Sidebar layout wrapper with links to Dashboard / Questions / Roles / Users.
- Add `AdminRoute` guard to `App.jsx` that checks `user.role === 'admin'`.

## Verification
- Non-admin user hitting `/api/admin/stats` receives 403.
- Admin sees correct user count and total questions.
