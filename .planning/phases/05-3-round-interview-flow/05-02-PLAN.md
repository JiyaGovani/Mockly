# 05-02-PLAN: Technical/HR Rounds Integration & Placement Hub UI

## Overview
Connect Technical and HR rounds to hybrid/LLM AI evaluation and build the full 3-Round Placement UI flow with lock notifications and scorecard cards.

## Task Breakdown

### Task 1: Technical & HR Controllers
- **File**: `server/src/controllers/placementController.js`
- Implement:
  - `POST /api/placement/technical/start`: Prepares technical interview session (3 Easy, 4 Medium, 3 Hard).
  - `POST /api/placement/technical/submit`: Evaluates answers via hybrid AI scoring; checks pass mark (>= 75%).
  - `POST /api/placement/hr/start`: Prepares HR behavioral interview session.
  - `POST /api/placement/hr/submit`: Evaluates HR responses with LLM-heavy scoring; checks pass mark (>= 70%).

### Task 2: Placement Hub & Round Workspaces UI
- **Files**:
  - `client/src/pages/PlacementHub.jsx`: 3-stage progress timeline (Aptitude -> Technical -> HR), locked round indicators with lock icons, attempt badges (e.g., "Attempt 1/3"), and start round CTA buttons.
  - `client/src/pages/AptitudeWorkspace.jsx`: MCQ test UI with radio selections and submit action.
  - Navigation route additions in `client/src/App.jsx` and navbar header.

## Verification
- End-to-end user path tested: Aptitude MCQ pass -> Technical unlock -> HR unlock -> Placement completion badge.
