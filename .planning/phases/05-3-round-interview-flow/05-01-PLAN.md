# 05-01-PLAN: Backend Placement Models, Aptitude MCQ Engine & Round Gating

## Overview
Implement the MongoDB schemas, controller routes, and round gating middleware to enforce sequential progress (Aptitude -> Technical -> HR) and a 3-attempt limit per round.

## Task Breakdown

### Task 1: Create ThreeRoundAttempt Schema & Model
- **File**: `server/src/models/ThreeRoundAttempt.js`
- **Fields**:
  - `userId`: Ref User
  - `roleId`: Ref Role
  - `status`: String enum `['in_progress', 'passed', 'failed', 'locked']`
  - `rounds`:
    - `aptitude`: `{ attemptsCount: Number (default 0), passed: Boolean, score: Number, answers: Array, completedAt: Date }`
    - `technical`: `{ attemptsCount: Number (default 0), passed: Boolean, score: Number, sessionId: Ref InterviewSession, completedAt: Date }`
    - `hr`: `{ attemptsCount: Number (default 0), passed: Boolean, score: Number, sessionId: Ref InterviewSession, completedAt: Date }`

### Task 2: Create Placement Controller & Gating Logic
- **File**: `server/src/controllers/placementController.js` & `server/src/routes/placementRoutes.js`
- Implement:
  - `GET /api/placement/status`: Returns current round status, scores, and remaining attempts.
  - `POST /api/placement/aptitude/start`: Retrieves 10 MCQ questions for the user's role.
  - `POST /api/placement/aptitude/submit`: Grades MCQ responses instantly, checks pass condition (>= 70%), updates attempt count and round status. Locks round if attempts reach 3 without passing.

## Verification
- Test script verifying attempt counts incrementing up to 3 and locking upon failure.
